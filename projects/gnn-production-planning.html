Graph Neural Networks for Production Planning

Exploring graph neural networks for vulcanizing planning decisions in rubber manufacturing.

1 / 2

Field

Machine learning

Topics & tools

  • Industrial Production Planning

Overview

This project explored graph neural networks (GNNs) for the Vulcanizing Planning Decision Problem in rubber manufacturing, representing the relationships between jobs, machines, and production constraints.

Graph representation

The model used message passing across machine–job graphs to represent scheduling dependencies and variable–constraint relationships, incorporating demand and resource constraints.

Model development

Work focused on developing and tuning the GNN architecture and evaluating the balance between scalability and predictive accuracy on large problem instances.
