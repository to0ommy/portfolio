Overview

I built an image classification project in PyTorch using Fashion-MNIST, a dataset of 70,000 clothing images spanning categories such as shoes, dresses, and pants.

Architecture comparison

I implemented three neural network architectures and compared their image recognition accuracy. TinyVGG achieved the highest accuracy among the models evaluated in this project.
